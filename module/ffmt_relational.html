Spelling of the relational operators: == / .eq., /= / .ne., < / .lt., <= / .le., > / .gt. and >= / .ge.. The two spellings are the same operator, also in operator(...).

CUDA kernel launches (<<< ... >>>) and code protected by formatter directives are not changed.
