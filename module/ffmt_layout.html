Writes the formatted text of a tokenized file: statements indented by their nesting depth, continuation lines aligned or indented by a fixed amount, comment lines indented like the code around them, and within each line the blanks and letter case that compute_gaps and compute_case ask for. Trailing blanks are removed.

Items protected by formatter directives (see ffmt_directives) are written as they are.

private function fitting_column(w, src, tokens, f, lend, candidates, from, prefix, always_original) result(col)

The first of the candidates columns at which the output line fits within the line length, or the smallest if none fits. The last candidate is the line's original column: if only that one fits, the line is recorded in long_lines. When lines are split (w%keep_original false), the original column is not a candidate for code, since splitting will make the line fit; it is still used if always_original is true (for comments, which are not split). Also when lines are split, a candidate other than the last is accepted if the line can be split to fit there: if its first piece up to a possible break fits.
