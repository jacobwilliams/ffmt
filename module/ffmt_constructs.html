Classifies statements by their role in the block structure: opening a construct or program unit, continuing one (else, case, contains, ...), or closing one.

Classification looks only at a statement's code tokens. Keywords are not reserved in Fortran, so a keyword followed by =, => or % is treated as a variable (end = 1).
