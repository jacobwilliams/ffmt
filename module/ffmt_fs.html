Portable file system access that standard Fortran lacks: listing a directory and telling directories from files. Written in Fortran with interfaces to opendir, readdir and closedir, which POSIX systems and MinGW-w64 (gfortran on Windows) provide.

The layout of struct dirent differs between systems, and gfortran's preprocessor does not say which system it is compiling for, so the layout is found at run time: the offset of d_name is where the . and .. entries, which every listing has, show their names. The known layouts are Linux (offset 19), macOS (21), FreeBSD (24), and MinGW or macOS with 32-bit inodes (8). Where the layout has a d_type field it is used; otherwise a directory is recognized by opening it.

public subroutine list_directory(path, entries, stat)

The entries of directory path, without . and .., in the order the system returns them. Links to directories are reported as ENTRY_OTHER, so a walk does not follow them. stat is nonzero if the directory cannot be read, or its entries cannot be decoded.
